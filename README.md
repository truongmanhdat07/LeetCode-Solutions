# LeetCode Solutions

A curated repository of my daily LeetCode problem-solving journey, focusing on mastering Data Structures & Algorithms (DSA), writing clean code, and achieving optimal time-space complexity.

## Key Objectives
* **Consistency:** Solving at least 1–2 problems daily to sharpen algorithmic thinking.
* **Optimization:** Analyzing time and space complexity ($O(N)$, $O(\log N)$, etc.) for every submission.
* **Clean Code:** Writing readable, maintainable, and well-structured implementations.

## Tech Stack & Tools
* **Primary Language:** C / C++
* **Platform:** [LeetCode](https://leetcode.com/)
